# 笔画 ЧЕРТА — Тренажёр китайской каллиграфии HSK

Мобильное веб-приложение для изучения китайских иероглифов с акцентом на правильный порядок черт.

## 🎯 Возможности

- **6 уровней HSK** с тематическими пачками слов
- **Интерактивная практика** рисования иероглифов пальцем/мышью
- **Реальное время сравнение** с эталоном: порядок черт, направление, пропорции
- **Красная стрелка-подсказка** при неверном направлении
- **Система звёзд** (1-3★) за качество начертания
- **Офлайн-режим** с кэшированием данных в IndexedDB
- **Тёмная тема** для комфортной практики
- **Адаптивный интерфейс** для управления одной рукой

## 📊 Структура данных

### Уровни HSK

- **HSK 1** (Основы) — 150 слов, 11 тематических пачек
- **HSK 2** (Повседневность) — 150 слов, 10 тематических пачек
- **HSK 3** (Расширенный) — 60 слов, 5 тематических пачек
- **HSK 4** (Продвинутый) — 48 слов, 4 тематических пачки
- **HSK 5** (Профессиональный) — 48 слов, 4 тематических пачки
- **HSK 6** (Мастер) — 60 слов, 5 тематических пачек

**Всего: ~516 слов** (можно расширить до 5000+)

### Тематические пачки

Каждая пачка содержит 10-15 слов по теме:
- Приветствия и вежливость
- Числа
- Люди и семья
- Время
- Места
- Еда и напитки
- Действия
- Описания
- Предметы
- Вопросы
- Грамматика
- Тело и здоровье
- Погода и природа
- Транспорт
- Одежда
- И многие другие...

### Алгоритм сравнения жестов

Файл `src/lib/matcher.ts` содержит алгоритм сравнения пользовательской траектории с эталоном:

1. **Передискретизация** по длине дуги (28 точек)
2. **Сравнение позиций** с учётом порядка появления
3. **Проверка направления** (угол вектора)
4. **Детекция разворота** (черта задом наперёд)
5. **Допуск ~10%** для мелких дрожаний

```typescript
// Пример использования
const result = comparePointArrays(userPoints, refPoints, 0.10);
// result.shape: 0..1 (1 = идеально)
// result.reversed: boolean (черта задом наперёд)
// result.dirDeg: расхождение направлений в градусах
```

## 📦 Источники данных

### Векторы черт
Данные о чертах загружаются из **[Make Me a Hanzi](https://github.com/skishore/makemeahanzi)** — открытой базы с векторами черт для 9500+ иероглифов.

- Файл: `graphics.txt` (~50MB)
- Кэшируется в IndexedDB для офлайн-режима
- Загружается при первом запуске

### Списки слов HSK
Основаны на официальных списках HSK с адаптацией для удобного заучивания.

## 🎨 Дизайн

- **Визуальный стиль**: Минимализм с акцентом на каллиграфию
- **Цветовая схема**: Бумага + тушь + киноварь (красная печать)
- **Шрифты**: Forum (заголовки), Manrope (текст), Ma Shan Zheng (иероглифы)
- **Анимации**: Плавные переходы, stroke-dashoffset для рисования черт

## 📱 Особенности интерфейса

- **Мобильный каркас** с амбиентным фоном
- **Сетка 米字格** на холсте для практики
- **Кнопки у большого пальца** (Отмена, Подсказка)
- **Вибрация** при успешном начертании
- **Тосты** с подсказками при ошибках

## 🔧 Расширение данных

### Добавить новые слова в HSK

Откройте соответствующий файл `src/data/hsk{N}.ts` и добавьте в пачку:

```typescript
{
  word: '学习',
  pinyin: 'xué xí',
  en: 'study',
  ru: 'учиться',
  chars: ['学', '习']
}
```

### Добавить новую пачку

```typescript
{
  id: 'h1-new-topic',
  title: 'Новая тема',
  subtitle: 'описание',
  words: [/* массив слов */]
}
```

### Загрузка до 5000 слов

Для расширения до полного набора HSK (5000 слов):
1. Скачайте официальный список HSK
2. Разделите на тематические пачки
3. Добавьте в соответствующие файлы `hsk{N}.ts`
4. Векторы черт автоматически загрузятся из Make Me a Hanzi
