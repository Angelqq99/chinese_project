# 笔画 ЧЕРТА — Тренажёр китайской каллиграфии HSK

Мобильное веб-приложение для изучения китайских иероглифов с акцентом на правильный порядок черт.  
Работает полностью **офлайн** после первой загрузки данных.

## 🎯 Возможности

- **6 уровней HSK** с тематическими пачками слов (слова разбиты по темам).
- **Интерактивная практика** рисования иероглифов пальцем или мышью.
- **Реальное время сравнение** с эталоном: порядок черт, направление, форма.
- **Красная стрелка-подсказка** при неверном направлении и начальной точке.
- **Система звёзд** (1–3 ★) за качество начертания и правильность.
- **Случайная практика** — бесконечный режим для повторения любого слова.
- **Офлайн-режим** — данные черт кэшируются в IndexedDB.
- **Тёмная тема** для комфортной работы в любое время.
- **Адаптивный интерфейс** с управлением одной рукой.

### Алгоритм сравнения жестов

Файл `src/lib/matcher.ts` содержит алгоритм сравнения пользовательской траектории с эталоном:

1. **Передискретизация** по длине дуги (28 точек).
2. **Сравнение позиций** с учётом порядка появления.
3. **Проверка направления** (угол вектора).
4. **Детекция разворота** (черта задом наперёд).
5. **Допуск ~10%** для мелких дрожаний.

```typescript
// Пример результата сравнения
const verdict = matchStroke(userPoints, refStrokes, expectedIndex);
// verdict.kind: 'perfect' | 'accepted' | 'reversed' | 'order' | 'repeat' | 'tiny'
// verdict.shape: 0..1 (1 — идеально)

📦 Источники данных
Векторы черт
Данные о чертах загружаются из Make Me a Hanzi — открытой базы с векторами черт для 9500+ иероглифов.

Файл: graphics.txt (~50 МБ) из папки public/.

Кэшируется в IndexedDB для офлайн-режима.

Загружается при первом запуске.

Списки слов HSK
Основаны на официальных списках HSK и разбиты по темам для удобного заучивания.

🎨 Дизайн
Визуальный стиль: минимализм с акцентом на каллиграфию.

Цветовая схема: бумага + тушь + киноварь (красная печать).

Шрифты: Forum (заголовки), Manrope (текст), Ma Shan Zheng (иероглифы).

Анимации: плавные переходы, рисование черт с эффектом пера.

📱 Особенности интерфейса
Мобильный каркас с амбиентным фоном и градиентами.

Сетка «米字格» на холсте для ориентира.

Кнопки управления (Отмена, Очистить, Подсказка) расположены под большим пальцем.

Вибрация при успешном начертании (на поддерживаемых устройствах).

Тосты с подсказками при ошибках и рекомендациями.

🔧 Расширение данных
Добавление новых слов
В файле src/data/characters.ts структура уровней определена через массив LEVELS.
Чтобы добавить новое слово, найдите нужную пачку и добавьте объект:

typescript
{
  word: '学习',
  pinyin: 'xué xí',
  en: 'study',
  ru: 'учиться',
  chars: ['学', '习']
}
Если иероглифы отсутствуют в базе Make Me a Hanzi, их нужно будет добавить вручную.

Добавление новой пачки
typescript
{
  id: 'h1-new-topic',
  title: 'Новая тема',
  subtitle: 'краткое описание',
  words: [ /* массив слов */ ]
}
После изменения данных уровней они автоматически подхватятся при следующем запуске.
