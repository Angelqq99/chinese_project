# ЧЕРТА для Android

Это Android-приложение на Capacitor 8 с существующим React-тренажёром внутри
локального WebView. Сервер для работы приложения не нужен. В APK входят списки
HSK, `graphics.txt`, интерфейс и шрифты Forum/Manrope. Китайский текст использует
системные шрифты устройства. Доступ к интернету для практики не требуется даже
при первом запуске установленного APK.

## Запуск на телефоне

Нужны Node.js 22+, JDK 21 и Android Studio с Android SDK 36.
Минимальная версия устройства — Android 7.0 (API 24).

```sh
npm ci
npm run android:sync
npm run android:open
```

В Android Studio дождитесь синхронизации Gradle, выберите телефон с включённой
отладкой USB или эмулятор и нажмите Run. Альтернатива: `npm run android:run`.
После изменения React-кода повторите `npm run android:sync`.

Для сборки отладочного APK без IDE:

```sh
# Windows (PowerShell)
cd android
.\gradlew.bat assembleDebug

# Linux/macOS
cd android
bash ./gradlew assembleDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
На GitHub откройте Actions → Android → успешный запуск → Artifacts →
`cherta-android-debug`. Архив содержит APK для установки на телефон.
Эта сборка предназначена для проверки, а не для публикации в Google Play.

## Поведение на устройстве

- Системная кнопка/жест «Назад» возвращает из практики на главный экран;
  на главном экране сворачивает приложение.
- Вибрация вызывается через нативный плагин Haptics.
- Системные отступы обрабатывает Android-контейнер Capacitor; веб-интерфейс
  также учитывает CSS safe area, если она предоставлена WebView/браузером.
- На небольших и горизонтальных экранах практику можно прокручивать;
  кнопки располагаются после холста и не перекрывают рисунок.
- Прерванный жест и дополнительные пальцы не засчитываются как черта.
- Прогресс и тема хранятся локально. Прогресс из браузера автоматически
  не переносится в приложение. Удаление приложения может удалить данные.

## Проверка

```sh
npm run typecheck
npx playwright install chromium
npm run test:mobile
npm run android:sync
```

Playwright проверяет три размера экрана, отсутствие внешних сетевых запросов,
отмену жеста, завершение иероглифа, сохранение прогресса/темы и повторную
загрузку после ошибки. GitHub Actions дополнительно собирает настоящий debug APK.
Браузерные тесты не заменяют проверку на Android: перед выпуском проверьте
первый запуск в авиарежиме, системную навигацию, вибрацию, поворот, сворачивание
и восстановление приложения на реальном устройстве.

## Перед публикацией

Идентификатор приложения: `io.github.angelqq99.cherta`. До первой публикации
его можно изменить в `capacitor.config.ts` и Android-проекте. Для Google Play
нужны собственный ключ подписи, release AAB, финальные иконка/заставка, описание
и данные карточки магазина. Не коммитьте ключи подписи. В проекте есть базовая
векторная иконка ЧЕРТА; для магазина потребуется подготовить графику карточки.

## Устройство исходного проекта

- `src/data/hsk-full.ts`: встроенные уровни и словарь HSK 1–6.
- `src/lib/makemeahanzi.ts`: загрузка графики и кэш IndexedDB.
- `src/lib/matcher.ts`, `geometry.ts`: проверка траекторий.
- `src/screens/PracticeScreen.tsx`: холст, подсказки и результаты.
- `src/context/ProgressContext.tsx`: прогресс в localStorage.
- `src/lib/mobile.ts`: Android Back и нативная вибрация.
- `android/`: нативный проект; скопированные веб-ресурсы не коммитятся.

В исходном проекте `hskLoader.ts` содержит пример внешнего URL, но рабочий
тренажёр его не использует: `characters.ts` импортирует встроенный `hsk-full.ts`.
В части слов поле русского перевода пока содержит английский текст — это
свойство исходного словаря, а не мобильной оболочки.
